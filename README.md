# wp-health-check

ตรวจสุขภาพ **ปลั๊กอินและธีม** WordPress ทุกเว็บบนเซิร์ฟเวอร์ ด้วย PHP CLI ตัวเดียว รันตรงจาก GitHub ไม่ต้องเซฟไฟล์ เรียกใช้จากเซิร์ฟเวอร์ไหนก็ได้

ใช้ไล่หา plugin/theme ที่ไฟล์หายหรือเสียหาย เช่นโฟลเดอร์เหลือเปล่าหลัง auto-update พังกลางคัน ทำให้ปลั๊กอิน/ธีมหายไปจากหน้า WordPress admin

## คุณสมบัติ

- ตรวจได้ทั้ง **plugins และ themes** (เลือกเฉพาะอย่างใดอย่างหนึ่งได้)
- แยกปัญหาเป็น 3 ประเภท: **ว่างเปล่า**, **ไม่มีไฟล์หลัก**, **ไฟล์น้อยผิดปกติ**
- **จัดกลุ่มตามชื่อ** plugin/theme เพื่อแก้ทีละประเภทได้ พร้อมบอกว่าแต่ละตัวกระทบกี่เว็บ
- **สรุปจำนวนโดเมนที่มีปัญหา** (นับไม่ซ้ำ) และจำนวนรายการปัญหาทั้งหมด
- สแกนทุกเว็บทุกบัญชีใน `/home` หรือเจาะเฉพาะบัญชีเดียว
- รันแบบถ่อมตัว (low CPU/IO priority) ไม่รบกวนเว็บอื่นบนเซิร์ฟเวอร์
- ออกผลเป็นตารางอ่านง่าย หรือ CSV สำหรับเก็บ log
- **อ่านอย่างเดียว 100%** ไม่ลบ ไม่แก้ ไม่ย้ายไฟล์ใด ๆ

## ประเภทปัญหาที่ตรวจจับ

| สถานะ | ความหมาย | plugin | theme |
|---|---|---|---|
| `ว่าง!` | โฟลเดอร์ว่างเปล่า ไฟล์หายหมด | 0 ไฟล์ | 0 ไฟล์ |
| `ไม่มีหลัก` | ไฟล์เยอะแต่ไฟล์หลักหาย ใช้งานไม่ได้ | ไม่มี `.php` ที่มี `Plugin Name:` | ไม่มี `style.css` ที่มี `Theme Name:` |
| `สงสัย` | ไฟล์น้อยผิดปกติ ควรตรวจเพิ่ม | ไฟล์ ≤ threshold | ไฟล์ ≤ threshold |
| `ปกติ` | มีไฟล์ครบและมีไฟล์หลัก | — | — |

> หมายเหตุ: เครื่องมือนี้ตรวจ "ความครบถ้วนของไฟล์" ไม่ใช่สแกนมัลแวร์ การสแกนมัลแวร์ควรใช้เครื่องมือเฉพาะ เช่น Imunify360

## วิธีใช้ (รันตรงจาก GitHub)

```bash
URL='https://raw.githubusercontent.com/ufavisionseoteam19/wp-health-check/main/wp-health.php'

# ตรวจทั้ง plugins + themes ทั้งเครื่อง
curl -s "$URL?v=$(date +%s)" | php

# แสดงเฉพาะที่มีปัญหา (แนะนำสำหรับเซิร์ฟเวอร์เว็บเยอะ)
curl -s "$URL?v=$(date +%s)" | php -- --only-issues

# ตรวจเฉพาะ plugins / เฉพาะ themes
curl -s "$URL?v=$(date +%s)" | php -- --plugins
curl -s "$URL?v=$(date +%s)" | php -- --themes

# เฉพาะบัญชีเดียว
curl -s "$URL?v=$(date +%s)" | php -- --user=newkeydec2025

# ออกผลเป็น CSV เก็บไว้ดูย้อนหลัง (มีคอลัมน์ type แยก plugin/theme)
curl -s "$URL?v=$(date +%s)" | php -- --csv > wp-health-$(date +%F).csv
```

> `?v=$(date +%s)` ต่อท้าย URL เพื่อกัน cache ของ GitHub ให้ได้ไฟล์เวอร์ชันล่าสุดเสมอ

## ตัวเลือก (Flags)

| Flag | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `--plugins` | ตรวจเฉพาะ plugins | ตรวจทั้งคู่ |
| `--themes` | ตรวจเฉพาะ themes | ตรวจทั้งคู่ |
| `--user=NAME` | สแกนเฉพาะบัญชีผู้ใช้นี้ | ทุกบัญชีใน `/home` |
| `--base=PATH` | เปลี่ยนโฟลเดอร์ฐาน | `/home` |
| `--threshold=N` | มีไฟล์ ≤ N ถือว่าน่าสงสัย | `3` |
| `--maxdepth=N` | จำกัดความลึกการค้นจาก base | `4` |
| `--exclude=a,b,c` | ยกเว้นชื่อ plugin/theme (คั่นด้วยคอมมา) | - |
| `--csv` | แสดงผลเป็น CSV | ตาราง |
| `--only-issues` | แสดงเฉพาะตัวที่มีปัญหา | แสดงทั้งหมด |
| `--no-progress` | ปิดข้อความความคืบหน้า | แสดง |

## วิธีแก้เมื่อเจอปัญหา

สคริปต์ไม่แก้ไขให้ — ต้องลงมือเอง:

1. ลบโฟลเดอร์เปล่า (ลบได้เฉพาะโฟลเดอร์ว่าง):
   ```bash
   rmdir /home/USER/DOMAIN/wp-content/plugins/ชื่อปลั๊กอิน
   # หรือธีม
   rmdir /home/USER/DOMAIN/wp-content/themes/ชื่อธีม
   ```
2. ติดตั้งใหม่:
   - ของฟรี: WordPress admin → Plugins/Appearance → Add → ค้นชื่อ → Install
   - ของ Pro: ดาวน์โหลด .zip จากผู้ขาย แล้ว Upload

เนื่องจากจัดกลุ่มตามชื่อให้แล้ว สามารถแก้ทีละกลุ่ม เช่น blocksy ว่าง 6 เว็บ → เตรียมไฟล์ครั้งเดียว ไล่ติดตั้งทั้ง 6 เว็บ

## ตั้งให้รันอัตโนมัติ (ทางเลือก)

ตรวจทุกวันแล้วเก็บ CSV ไว้ดู pattern ย้อนหลัง ใส่ใน crontab (`crontab -e`):

```bash
0 3 * * * mkdir -p /root/wp-health-logs && curl -s "https://raw.githubusercontent.com/ufavisionseoteam19/wp-health-check/main/wp-health.php?v=$(date +\%s)" | php -- --csv > /root/wp-health-logs/$(date +\%F).csv
```

## ความปลอดภัย

- สคริปต์เป็น read-only ไม่มีคำสั่งเขียน/ลบ/แก้ไฟล์เว็บ
- การรันแบบ `curl | php` ดึงโค้ดจาก GitHub มารันทันที — ควรเป็น repo ของคุณเองและตรวจโค้ดก่อนใช้บน production โดยเฉพาะเมื่อรันด้วย root
- อย่าใส่ข้อมูลลับ (path จริง ชื่อลูกค้า) ลงในโค้ดที่เปิด public

## ข้อกำหนด

- PHP CLI (ทดสอบบน PHP 8.3 ใช้ได้ตั้งแต่ PHP 7.x)
- สิทธิ์อ่านโฟลเดอร์เว็บ (ปกติใช้ root)
